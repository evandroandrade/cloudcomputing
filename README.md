# Cloud Computing

Este projeto é uma página simples sobre **Cloud Computing**, hospedada no [GitHub Pages](https://evandroandrade.github.io/cloudcomputing).

## Como acessar

Acesse o site em: [https://evandroandrade.github.io/cloudcomputing](https://evandroandrade.github.io/cloudcomputing)

## Sobre

Esta página foi criada para demonstrar como hospedar sites estáticos utilizando o GitHub Pages.  
Você pode editar o arquivo `index.html` para personalizar o conteúdo do site.

---

**Como publicar seu próprio site:**
1. Crie um arquivo `index.html` na raiz do repositório.
2. Ative o GitHub Pages nas configurações do repositório.
3. Pronto! Sua página está disponível.
